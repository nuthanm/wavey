# Contributing to Wavey

Thanks for helping improve Wavey.

## Development setup

1. Follow the [Quick start](README.md#quick-start-local) in the README.
2. Use `npm run dev:full` so `/api` routes work locally.
3. Before opening a PR, run:

```bash
npm run lint
npm run build
```

## Guidelines

- Keep PRs focused and small when possible
- Match existing TypeScript and UI patterns
- Do not commit secrets, cookies, or `.env.local`
- Update the README when behavior or setup steps change
- Be respectful of copyright and platform terms in docs and UX copy

## Pull requests

1. Fork and create a branch from the default branch
2. Describe what changed and why
3. Link related issues if any
